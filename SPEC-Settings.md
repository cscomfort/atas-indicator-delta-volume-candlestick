# Settings
## Visualization tab
Ensure the following are placed in a "Visualization" tab.
### Delta Profile
- Bid Color (set to our default blue)
- Ask Color (set to our default red)
### Volume Profile
- Color (set to our default "white")
- Enable/Disable POC Highlight (boolean)
  - Color option if enabled
    - POC Highlight (set to our default yellow/gold)
### Delta Divergence
- Enable/Disable Delta Divergence (boolean)
- Color options if enabled
  - Positive Divergence Color (set to our default red)
  - Negative Divergence Color (set to our default blue)
